一些建议:  
时间戳用"double"标识  
流水号标识可以用"uint64"  
状态枚举用uint8(256中状态,超过256种定义的可以用uint16)

# 协议工具使用说明
1.在协议配置文件夹(D:/jjq/game/mainproto)放上xml协议定义的xml  
2.执行D:\jjq\game\tools\qatools下的bat脚本
```js
node buildproto.js  -client "D:/jjq/game/gameclient/src/game/network" -server "D:/jjq/game/gameserver/Protocols/ProtoBody" -out "D:/jjq/game/mainproto"
```

-client 客户端输出的协议定义文件夹  
-server 服务器输出的协议定义文件夹  
-out 协议xml配置文件夹  


```xml
<proto id="1101" name="UploadGif" desc="上传Gif请求" type="req">
    <protobuf type="string" name="datas" desc="图片数据" ></protobuf>
</proto>
<proto id="1102" name="UploadGif" desc="上传GIF" type="revc">
    <protobuf type="uint8" name="errorID" desc="错误码" ></protobuf> 
    <protobuf type="string" name="path" desc="上传成功路径" ></protobuf>
</proto>

<proto id="1003" name="Kick" desc="踢出通知" type="ntf">
        <protobuf type="uint8" name="reason" desc="踢出原因  /// <summary>
    /// 被踢原因
    /// </summary>
    public enum KickReason {
        AccountDuplicate,//同名账号登录
    }" ></protobuf> 
</proto>


<proto name="stServerConfig">
    <protobuf type="uint32" name="HeartMillisecond" desc="心跳间隔毫秒数" ></protobuf> 
    <protobuf type="string" name="ServerTime" desc="服务器时间" ></protobuf> 
</proto>


```
```
type="req"请求
type="revc"返回
type="ntf"主动通知

<proto name="stServerConfig"> 这种无type标签定义的属于结构体
```
如果结构体来源其他定义文件用from标识:

```xml
<protobuf type="stSimpleUser" name="UserInfo" desc="发送者信息" from="BaseProto"><protobuf>
```
from字段`import {stSimpleUser} from "./BaseProto";`  


**字段说明**  
```
"string",
"uint8",
"int16",
"uint16",
"uint32",
"double",   -->     64float
"uint64",   -->     客户端用uint64类封装
"int",      -->     32int
"float"     -->     32float


"arraybuffer" -->   len(int32)+byte[] 流结构(数据字节序不受系统大小端影响)
         _______    ______________           
        |       |  |              | 
        | Int32 |  |  byte[] data |  
        | length|  |              |
        |_______|  |______________| 
    
```
**枚举定义说明**  
```xml
<proto name="EMailStatus" type="enum" desc="邮件枚举" target="cs">
    <protobuf  name="ERROR" desc="邮件失败" value="11"></protobuf>
    <protobuf  name="SUCCEED" desc="收到邮件成功" ></protobuf>
</proto>
```
type="enum" `类型`  
target="cs" `是否要生成指定的代码 cs客户端服务器 c客户端 s服务器`  
value="11" `需要自定义的时候用value标识`  

**流结构arraybuffer说明**  

使用范例:  
```xml
<proto id="11010" name="AmaVideoPush" desc="发送视频音频流" type="req">
    <protobuf type="arraybuffer" name="video" desc="视频流数据" ></protobuf>
</proto>

<proto id="11011" name="AmaVideoPush" desc="视频音频流通知" type="ntf">
    <protobuf type="arraybuffer" name="video" desc="视频流数据" ></protobuf>
</proto>
```
